# 📊 E-Commerce Data Analysis & Power BI Dashboard

## 📌 Project Overview

This project was completed as part of the **Data Analysis Internship Program at Primeor Solutions**.

The project focuses on analyzing an **E-Commerce dataset** and transforming raw data into meaningful business insights using:

- **Microsoft Excel**
- **MySQL**
- **Microsoft Power BI**

The complete workflow covers **data cleaning, Excel analysis, Pivot Tables, SQL analysis, business insights, and interactive Power BI dashboards**.

The project follows the three major levels provided in the internship task:

> **Level 1:** Data Understanding & Cleaning (Excel)  
> **Level 2:** Data Analysis (SQL)  
> **Level 3:** Power BI Dashboard

---

# 🎯 Project Objectives

The main objectives of this project were to:

- Clean and prepare the raw E-Commerce dataset
- Perform basic analysis using Microsoft Excel
- Create Pivot Tables and charts
- Import the cleaned dataset into MySQL
- Perform SQL-based business analysis
- Identify important sales, profit, product, customer, and shipping trends
- Create an interactive Power BI dashboard
- Present business insights through effective data visualization
